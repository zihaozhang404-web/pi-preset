# 测试 C：四臂对照实验

同一模型、同一环境、同一探索预算（每步恰好一次探索信号，eps 相同），每臂每场景 300 个独立种子（1..300）。

参数固定为：a=0.9, b=1.0, k0=0.6, mu=0.02, eps=0.05, e0=1.0, horizon=200, settle_tol=0.02。

诚实性说明：四臂共享同一初值与预算，但每臂使用**独立种子**，因此比较是两组独立样本，不做配对声称。

区间宽度说明：置信区间塌缩成一个点，表示该臂在重复试验中零方差（确定性策略 + 确定性扰动），此时两点之差是一次确定比较，不是抽样估计，不能读作“样本极大所以显著”。
