# 测试 B：数学控制层验证

对 pi_model.py 的直接调用（与 control.js 已交叉验证一致）。

## B1 正负误差对称收敛（a=0.9, b=1, k=0.6, rho=0.3, 无扰动）

| e0 | 步数 | |e_1| | |e_5| | |e_10| | 稳定判定 |
|---|---|---|---|---|---|
| +1 | 10 | 0.3000 | 0.0024 | 0.0000 | rho=0.30 < 1 |
| -1 | 10 | 0.3000 | 0.0024 | 0.0000 | rho=0.30 < 1 |

- 对称性 |e(t,+) + e(t,-)| = 0 在 30 步内逐点成立：**True**

## B2 不稳定增益被识别（a=2.0, b=1, k=0, rho=2.0）

- rho = 2.00 ≥ 1：负结论被正确给出
- 有限性标志 finite = **False**（溢出即停止，不产出伪数值）
- 停止前步数 = 1024，末值 = inf

## B3 有界扰动下的误差界（a=0.9, b=1, k=0.6, eps=0.05, w_max=0.1）

- 理论稳态界 (b·eps + w_max)/(1-rho) = 0.2143
- 200 次试验（horizon=400, e0=0）中的最大值 = 0.1400
- 结论：**未越界**

## B4 动作限幅被计数（umax=0.2, e0=10）

- 饱和步数 = 16 / 50
- 控制量最大值 = 0.2000 ≤ umax = 0.2
- 误差仍然收敛：final |e| = 0.0000

## B5 增益投影（kmin=0.5, kmax=0.7，自适应臂）

- 全部 500 步的 k 均落在 [0.5, 0.7]：**True**
- 该集合内最大 rho = |0.9 - 0.7| = 0.20 < 1：投影本身即保证稳定
- 大 mu=0.2 下仍然有限：finite = True

## B 小结

| 检查 | 结果 |
|---|---|
| B1 对称收敛 | 通过 |
| B2 不稳定可识别 | 通过 |
| B3 有界扰动不越界 | 通过 |
| B4 限幅计数 | 通过 |
| B5 增益投影 | 通过 |
